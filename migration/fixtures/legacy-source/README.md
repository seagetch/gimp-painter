# Pinned source assets (WBS 02.008)

These are **source-derived assets**, not files generated by an observed legacy
application run. `assets.tsv` locks all bytes in the pinned source directories;
`manifest.json` locks that table and its counts. They record 386 files:

- 177 `.myb` brushes: 176 JSON version 3, one text version 2
  (`data/mypaint-brushes/deevad/thin_watercolor.myb`)
- 178 preview PNGs, eight layer-preset JSON definitions
- Four notices and 19 build/support files

Every row includes the full source path, Git blob ID, SHA-256, byte length,
asset kind, brush format version, and applicable notice location. No JSON,
line ending, unknown field, or text brush is rewritten. `.myb` source bytes,
previews, parent names, brush/texture references and source preset definitions
remain independently retrievable at the full pinned commit.

From the migration checkout, verify against Git object bytes:

```sh
python3 tools/freeze_legacy_assets.py
python3 -m unittest discover -s migration/tests -p test_legacy_assets.py -v
```

Materialize a copy into an empty caller-selected test directory:

```sh
python3 tools/freeze_legacy_assets.py --materialize ../legacy-test-assets
```

The checkout must contain the pinned commit and blobs. In a partial clone Git
may fetch missing blobs from its configured origin. An unavailable source is a
verification failure, never permission to substitute modern installed brushes.
`--write` regenerates metadata and must be reviewed as a baseline change;
ordinary verification does not modify the lock. Materialization never overwrites
an existing file. The notices travel with a materialized source bundle.

The full source tree can also be checked out independently:

```sh
git worktree add --detach ../gimp-painter-legacy afa43fae3e920210146abed514f136fd49f671b5
```

Asset hashes do not establish successful loading, rendering, edit/save/reopen
compatibility, or runtime output equivalence. Those remain separate acceptance
criteria (02.010, 19, 20, 21, 22, 31). Source presets likewise do not replace the
legacy CloneLayer/FilterLayer XCF fixtures required by 02.005–02.007.
