# Original Video callback foundation (16.022, not a native route)

Pinned old source is afa43fae3e920210146abed514f136fd49f671b5. `old-oracle.c` contains the exact original Video callback and nine immutable pattern tables, with primitive typedefs/MIN/global state and a harness-only defined-domain guard. `old-sources.tar.gz` preserves complete pinned sources; `old-source.json` binds hashes, exact fragments and argument/iterator excerpts. No old GIMP application, UI, plug-in executable, Edge or string runtime is invoked.

Original six slots are run mode, image, drawable, pattern-number, additive and rotated. The three operation arguments are declared INT32. Original noninteractive setup copies them without bounds checks: only pattern0–8 indexes the nine tables safely. Negative or ≥9 indices are undefined, not an extra valid mode to emulate. Both flags use any nonzero signed value, including INT_MIN/INT_MAX. RGB and RGBA are supported; alpha copied, hidden RGB processed. Nonadditive retains only selected color channel. Additive saturates twice the selected channel and leaves the two other channels unchanged.

Crucial coordinate contract: original gimpregioniterator passes drawable-local absolute x/y, including selection ROI origin. Rotation swaps table row/column coordinate roles, not the image geometry. Phase is not reset at crop/tile/chunk boundaries, and layer image offsets are not added. The existing native CropRaster worker signature omits origin; any future Video overload must carry an immutable origin rather than blindly reusing a crop-relative point kernel. Original region iterator signed selected-area multiplication is a separate transport bound, not exercised by this scalar foundation.

Independent oracle represents tables as rows of channel-character strings and uses quotient/remainder coordinate reduction and branch-based per-channel saturation, distinct from old flattened indexing and additive MIN expression. Shared immutable table data is the historical specification, not an independently rediscovered pattern. The separately parsed row representation is verified against exact archived C initializer data. Both normal and ASan/UBSan runs pass13,708,800 comparisons:9 patterns×25 signed flag pairs, RGB/RGBA, all256 values for each of three channels (not all16M simultaneous RGB combinations), all256 varying alpha values, every phase at a non-period-aligned nonzero origin, and0/near-INT_MAX coordinates. Alpha0 exercises hidden RGB. Four private original-C mutants fail: reset ROI phase, ignore rotation, wrap instead of saturating additive output, erase alpha.

Fourteen invalid index/negative coordinate/channel/null cases are rejected by the **harness guard before calling old code** with output unchanged where present. This proves test admission safety, not historical validation or any new native validation implementation. No native Filter admission, owner merge, lifecycle, XCF roundtrip, parameter UI, precision extension or genuine old-artwork compatibility is claimed. Exact old INT32 writer behavior and native route/storage remain later tasks.
