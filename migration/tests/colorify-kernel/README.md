# Isolated immutable Colorify pixel kernel — original16.022

`FilterColorifyKernel` is a private typed value/LUT implementation only; no core route, raster transport, argument converter or storage schema is added. Its copied RGBA metadata and lookup tables are immutable. All four components must be finite and in[0,1]; unsupported input is rejected, not clamped. Alpha metadata (including negative zero) is retained while source pixel alpha is copied unchanged. Construction explicitly requires FE_TONEAREST and never changes the process rounding mode. The point function uses only precomputed integer tables thereafter.

Normal and selected ASan/UBSan/float-cast-overflow each pass the independent foundation oracle:268,435,456 RGB/RGBA comparisons and98,685 binary64 tint-boundary probes. Separate normal/sanitizer contracts test20 invalid RGBA components, three non-nearest rounding modes, nine invalid pixel/index calls and eight separate/exact/partial alias cases. All checks and source reads precede output publication. White254 and separate truncations are retained. Two private production-header mutants (combined luminance and omitted rounding precondition) are rejected; live sources are never mutated.

The sanitizer instruments the isolated comparison/adapter/contract code and inline kernel, not GIMP or system libraries; LSan disabled. No old runtime, UI, default Edge, held diagnostic or native build is involved.
