and bundled Blinds child observation, byte equality with a genuine old4096²
PDB result, and Save/reopen equality. Startup plug-in queries do not count as
private Filter execution. Every observed private executable must belong to the
intended runtime. A version-only or ordinary-layer smoke cannot satisfy this
new gate.

it is not an installed/relocated application or full current-source aggregate.

unrelated startup query alias and failed; its original source and result are
preserved in `../filter-package-harness-development`.

with member hashes and raw-raster digest in the adjacent JSON. Its input exactly
