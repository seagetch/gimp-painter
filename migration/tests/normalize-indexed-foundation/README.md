# Normalize indexed scalar foundation

Literal indexed_normalize body from old commit afa43fae3e920210146abed514f136fd49f671b5, contrast-normalize.c; GPL source attribution retained through pinned source. Only bounded nonempty 1..256-entry RGB colormaps execute. A mock getter supplies the mutable palette and exact signed count; setter asserts the same image, pointer and count, once. This is not a claim about real getter allocation ownership, native palette replacement, image-wide history or indexed rendering.

The independent integer oracle computes one shared min/max over all RGB entries. A nonflat palette maps each channel with integer floor(255*(channel-min)/(max-min)); flat palettes remain unchanged. Normal and ASan/UBSan/float-cast-overflow each pass42,896 palettes: all32,896 byte min/max pairs and10,000 deterministic random palettes. Unused array tail remains unchanged. Three executable causal mutants fail assertions: omit blue maximum, wrong scale, omit setter. The omitted-set mutant retains an unreachable setter reference to avoid a compile-only unused-function failure; only executed assertion failures count. Leak detection is disabled.

Empty/NULL palettes are not executed. Source inspection alone establishes that this old function does not receive or edit drawable index pixels, alpha or ROI; the fixture does not model those native objects. The separate RGB/Gray Normalize foundation and its undefined transparent/empty-domain caveats are unchanged. This package creates no production route, PDB adapter, colormap ownership policy, cancellation, native persistence or UI, and does not close16.022.
