## Representation and audit

Existing integer offset fields and their layout remain unchanged; fractional device-origin translation and press anchors are appended to the shell. The shared rotate matrix and its inverse carry the fraction even at zero angle. Full transforms, raster paint, selection, canvas item outer CTMs, damage and upright overlay anchors therefore share one translation. Pure zoom/unzoom helpers intentionally remain pre-matrix coordinates. Ordinary fractional pan invalidates the entire raster cache, rather than shifting it by rounded pixels.

`source-use-audit.json` is the **preimplementation** audit (22 files, 212 uses), not a passing test report. Explicit integer set-offset, scale-by-values, dot-for-dot/resolution grid change, zoom-on-resize and empty-shell paths clear the fraction. Native integer incremental scrolling preserves it unless a clipped axis resets to an integer bound; such a reset invalidates the full cache. Releasing a pan clears press anchors but preserves the displayed origin. Title offsets include the fraction. Existing integer scrollbar values and integer-rounded ruler extents remain native UI representations, not claims of exact old widget behavior. Whole-task closure requires the original acceptance review, not just this bridge.
