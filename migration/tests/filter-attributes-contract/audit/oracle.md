# Original 15.006 ordinary attributes

The pinned old Filter class delegates completed/loaded projection to its GimpLayer parent; its constructor stores native layer opacity/mode and projection queries the native layer mask. This is the original ordinary-attributes duty, not a requirement to execute the old Edge default. Current GimpFilterLayer derives from GimpLayer and inherits its GEGL node construction; `gimp_layer_update_mode_node` supplies mode and opacity, and `gimp_layer_get_node` connects the mask input. Normal legacy explicitly uses nonlinear RGB in the current mode registry.

The new fixture runs an actual Gaussian to completion first. For each of 27 mask/opacity/mode combinations it compares two projected pixels to a separate ordinary layer seeded with the same completed cache. This is independent native layer composition, NOT an independent Gaussian arithmetic oracle. Eighteen Normal comparisons additionally use source-over arithmetic from cache/input bytes with one u8 rounding tolerance. Multiply legacy and Painter Replace are bounded representative routes; all other modes, precision formats, groups and UI interactions are not claimed here. Reads cannot start a runner or mutate the completed cache. Prior pickable-opacity behavior is intentionally separate from visible projection.
