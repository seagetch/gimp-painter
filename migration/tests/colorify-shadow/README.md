# Colorify typed raw raster and ROI transport

This bounded original 16.022 checkpoint adds Colorify overloads to the existing raw raster and sole point-shadow engine. It does not admit a native Filter procedure, persist a tint, invoke old application code, or test UI. Existing operation enum values 0–3 and all previous overloads remain unchanged. The preceding immutable Colorify kernel is required; old boxed tint information lost by the old XCF writer remains unrecoverable and is never guessed.

The immutable validated LUT is copied before raster callbacks, including the initial shadow zero-fill. Raw processing uses a fixed 32-KiB buffer; cropped transport reuses existing zero-fill, CropRaster, bounded I/O, cancellation and atomic vector publication. Alpha is copied; hidden RGB is transformed normally. Promoted RGB uses alpha255. The original iterator's signed selected-area limit is retained, not Exchange's different signed-row policy. Pre-cancel fake rasters test allowed huge dimensions without allocation or I/O; this is not proof of huge-file processing. Construction rejects invalid finite-domain/rounding inputs before this API; the raw overload accepts only a previously validated immutable kernel.

Normal and five-C++-translation-unit ASan/UBSan/float-cast-overflow runs each pass 120 geometry/tint/layout scenes through vector, aliased vector and actual temporary-file spill, 134,217,728 independently calculated RGB comparisons with varying alpha, 130 raw/shadow cancellation and I/O-failure positions, source preservation and progress/flush checks. Caller-owned kernel deletion at first raw read or shadow zero-write cannot invalidate captured LUTs. Native C++14/no-RTTI is used; vptr and leak checking excluded. GLib and system dependencies are uninstrumented. All prior point-shadow fixtures run afterward, including Red Eye117,440,512 and Value Invert16,777,216 comparisons. A separate unchanged Exchange fixture also passes normal/sanitizer on these exact providers. Linked unused Edge implementation is never invoked; user-skipped old Edge/string runtime remains skipped.

Two private source mutants are rejected: removing selected-area rejection and skipping the Colorify pixel operation. C++14 first/double-header probes retain all four old enum values. First fixture compile failed only -Wmisleading-indentation; corrected formatting and complete rerun preserved. Mutation setup first used an ambiguous source anchor (no native execution), then a wrong row-policy mutation triggered a different valid rejection than expected; both failures retained before the isolated area-removal control passed. No production source was mutated for controls.

`results.json` and `exchange-regression.json` bind exact tested inputs; `sources.tar.gz` contains their union plus the original point fixture table, with post-run hashes unchanged. `python3 validate.py --check-source` validates current inputs; omit that flag to validate the immutable historical checkpoint. `run.py --output DIR` rebuilds Colorify and prior point regressions using pkg-config GLib. Source archives are evidence, not whole-app/whole-HEAD proof. Native admission, immutable tagged tint metadata, actual selection/component merge, owner-generation rules, XCF Save/Open and rendered portrait proof remain future route work.
