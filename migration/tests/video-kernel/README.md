# Immutable Video pixel kernel (bounded16.022 checkpoint)

`app/painter/filter-video-kernel.hpp` is a private C++14/no-RTTI value kernel, not a native Filter/PDB route or transport backend. It snapshots original signed pattern/additive/rotated controls and an explicit drawable-local origin. Pattern0–8, nonnegative signed32 origin, and nonnegative relative coordinates whose sum remains≤INT_MAX are checked before output. Any nonzero original signed flag remains true; original flag bits are retained. Pattern phase includes immutable origin and does not silently add image layer offsets or reset at crops/tiles.

Nine original pattern tables match the separately archived pinned source foundation. Normal and ASan/UBSan each pass13,708,800 independent row/coordinate/channel comparisons using that foundation's independent C reference; the original C callback is not linked. Adapter divides each absolute coordinate between nonzero origin and relative position to exercise addition. The matrix's inherited stdout says “harness guard”: here its named entry is replaced by the new product adapter, and no old callback is linked. Product-specific contracts additionally verify28 invalid input/origin/addition/channel/null cases with no writes,54 exact/forward/backward partial aliases, and immutable original flags/origin after caller options change. Alpha preserved; hidden RGB transformed. This exhausts individual component values, not all simultaneous16M RGB tuples.

Five private **product header** mutants fail: discarded origin, ignored rotation, wrong additive saturation, missing pattern admission, erased alpha. Missing-admission mutant runs constructor-only contracts so it never indexes an undefined table. Native C++14/no-RTTI first/double-inclusion compile routes are recorded in results.json; this is a private .hpp, outside the new C .h inventory gate, and no unrelated historical registration inventory is changed. Normal warnings and pedantic checks are fatal. ASan/UBSan cover the isolated kernel, adapter/reference and contracts, not any GIMP/GEGL dependency. LSan disabled.

Exact input archive/source hashes are retained; `python3 validate.py --check-source` binds current sources, omit flag for historical validation. `run.py --report PATH` and `mutations.py --report PATH` reproduce tests. No shared raw provider, native Filter route, owner merge/lifecycle, XCF decoder, persistence representation or UI was changed. Future raw transport must carry captured origin and retain original selected-area overflow policy. User-skipped old application/Edge/string runtime remains unexecuted.
