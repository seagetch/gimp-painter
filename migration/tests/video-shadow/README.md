# Video origin-aware raw/ROI transport — bounded16.022

Adds typed Video raw and whole-drawable shadow overloads to the existing sole point-shadow backend. Existing operation enum0–3 and prior overloads are unchanged. Raw kernel receives a captured immutable drawable-local origin; relative x/y are calculated from the global raster byte offset, not each32-KiB chunk offset. The shadow overload snapshots both options and ROI before callbacks and constructs origin from ROI.x1/y1 before zero-fill. It neither adds image layer offsets nor resets phase at crop/tile/row boundaries. Vector publication remains transactional; no_merge never authorizes merging private zeros.

Original gimp_rgn_iterator_src_dest uses signed `gint total_area=(x2-x1)*(y2-y1)`, so Video retains the selected-area limit, unlike Exchange's separate signed-row policy. Raw preflight validates width/height and origin+extent≤INT_MAX before read/write. Invalid pattern, alias and extent also fail before I/O. Huge metadata-only pre-cancel rasters verify domain checks without allocation; no huge-file processing claim.
