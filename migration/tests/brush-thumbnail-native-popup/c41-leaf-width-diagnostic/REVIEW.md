## Narrow change and exact boundaries

Only the existing separate owner diagnostic gains typed leaf wrappers and a strict
numeric collector. GtkImage/Text width and Pixbuf legacy get_size originals are
called exactly once; height slots remain unchanged to preserve baseline dispatch.
Audited static slots equal to the base original are installed. Unknown overrides
remain untouched and reported; dynamic types, incomplete bounds or failed restores
produce inconclusive results. Existing and late inherited copies are audited and
restored. Cached wrappers remain inactive exact passthroughs until the existing
collector terminates its owned child at the finish breakpoint. No GUI resume follows.

Callbacks use fixed storage, bounded parent traversal and numeric owner roles;
there is no callback allocation, printing, property/icon lookup, public size query,
widget retention or object dereference after the original callback. GimpImageWindow
gets a separate role, combined across windows including later instances. The phase snapshot alone does
not establish unique original-window ownership. Nested bucket totals overlap; a separate outer union
avoids summing them. The record protocol is fixed21rows with strict field/order,
transport, counter, restoration and summary-consistency checks.

Primary app sources, compact/Brush/Transform test source, shared tests.c, original
Meson, all26 protected files,3s/stable assertion, sanitizer options, leak guard,
owned-child controller and existing diagnostic build budget remain unchanged from
C40. Source/collector identity closure includes the generated leaf include.

## Coverage limits

These are selected leaf slots, not complete layout coverage. Excluded work includes
height, pre-vfunc ensure-style/resize, direct static pixbuf-render sizing, arbitrary
overrides and omitted classes. Low totals cannot rule these out. Full declared
leaf coverage is not whole-window coverage. Unknown overrides alone can yield a
valid partial capture; other fault flags are inconclusive. GType child enumeration
allocates a sibling list outside the measured timer and is not allocation-bounded.
No arbitrary class-cache restoration is claimed. The implementation is scoped to
GTK main-thread mutation and static base originals.

Exact upstream GTK3.24.49 image/text/pixbuf sizing implementations were read through
the official GNOME repository. They do not redispatch their own sizing vfuncs.
Debian patch-byte identity is not asserted. Actual native GTK-header compilation
and hosted runtime behavior are still unverified locally.
