# Colorify pinned-source numerical foundation — original16.022

No production/native route is added by this checkpoint. The original literal `plug-in-colorify` takes INT32 run mode, image, drawable and GIMP_PDB_COLOR (boxed GimpRGB). Registration is RGB/RGBA only. `colorify_func` and the lookup initialization are extracted exactly from afa43fae. The old path separately truncates R×.2126, G×.7152, B×.0722 into integer lookup tables; their sum indexes separately truncated tint-channel lookup tables. Combining luminance before truncation or rounding tint output changes pixels. White input with white tint becomes254, not255. Source alpha is copied (including alpha0 hidden RGB); tint alpha is unused by the arithmetic.

Normal and ASan/UBSan/float-cast-overflow each compare268,435,456 complete RGB/RGBA pixels (all16,777,216 RGB triplets ×8 tint vectors ×2 channel layouts), including transparent inputs, alpha preservation and RGB output sentinel preservation. Another98,685 coefficient probes exercise adjacent binary64 values around integer-output transitions. The oracle uses exact integer rational luminance and an independent integer simulation of binary64 multiply/nearest-even then truncation, not copied floating arithmetic. IEEE binary64 and FE_TONEAREST are checked. Two causal mutants fail: rounded tint at0/0/14 and combined luminance at0/1/4. This does not claim every binary64 tint was enumerated or another floating rounding mode.

Old PDB `gimp_param_spec_rgb(...,TRUE,NULL,...)` uses RGB validation/clamping; the procedure validator rejects any reported changed value. Finite RGBA components in[0,1] are therefore the supported argument domain, not an invitation to silently clamp malformed saved data. NaN/infinity/null/out-of-range need explicit rejection in the future converter/kernel. Their undefined legacy conversions are never executed here. Alpha must remain part of saved metadata even though unused by Colorify math.

ROI: original `gimp_rgn_iterate2` applies this point function to selected drawable regions and merges its shadow. Owner selection/component/alpha-lock, cancellation, private output, native precision and rendering remain separate future route work, not proven by this scalar foundation.

Old XCF limitation: the pinned writer's value dispatcher has no RGB/boxed-color case, so the original color argument falls through to UNSUPPORTED with zero payload. No tint can be recovered from that old wire; preserve raw bytes/cache and fail explicitly rather than invent a default. Current Filter arguments can retain immutable G_TYPE_VARIANT, and the current typed capsule can serialize a variant, but any new port color representation requires an explicit reviewed type/shape contract. This checkpoint does not change storage or claim old-application capture.

`run.py --report /tmp/colorify.json` reproduces the pure-source tests. No old application/plug-in/UI runtime, default Edge, held diagnostic or clean native build is invoked. LSan disabled. Original16.022 remains DOING with original criteria/dependencies unchanged.
