# Native MyPaint Preset/Custom selector

Bounded task 300, based on published task 299 (`1d00792a0e3936b829caeea4063e145ea005b328`, tree `5a887c7d5e05d269941a595fecdce7e1d569059a`). The real MyPaint thumbnail entry now uses task 298's `GimpPainterPopup` (`GTK_WINDOW_POPUP`), not GtkPopover or a decorated editor. One controller, canonical options model and retained notebook/views remain shared; each presentation host is ephemeral.

Live Preset selection and double activation keep the popup open. Custom cursor changes—including focused keyboard navigation—restore existing immutable snapshots, not mutable legacy brush objects. Rebuilding history preserves the stable append-only history index without triggering another restore. Model replacement/teardown callbacks cannot apply an old cursor ordinal to a replacement model. Tabs only remember page: after Custom selection followed by a different Preset, switching back to Custom leaves draft, `use-gimp-brush` and history count unchanged; explicit history selection still works. Escape/outside dismissal does not undo selection or save. No global Return/Space confirmation was added; focused children retain normal behavior.

## Verification

- **192 distinct native cases:** selector 32 (all original 29 plus 3 new), existing editor 43, compact options 62, MyPaint resource 49, factory 2 and context 4. History/source coverage within the selector aggregate is not counted twice.
- Scale-2 repeats of the native dismissal and keyboard/tab cases also pass; these two repeats are not added to the 192 distinct-case count.
- **Scoped ASan/UBSan: 32/32 PASS, no findings.** Twelve translation units instrumented; UBSan vptr excluded and LSan disabled. Remaining application archives/dependencies are uninstrumented, so this is not whole-application or leak-clean certification. The real-resource case completed (642.40 seconds under instrumentation); it was not skipped.
- **Two expected negative controls:** exact published-299 selector fails the actual compact on-canvas entry assertion; a reproducible source mutation removing only cursor preservation fails after a dirty keyboard restore. Both use the final tests. Earlier diagnostics are not additional passing tests.
- Selector aggregate uses the official `sessionrc-native-oncanvas` profile, production canvas-UI default TRUE and authenticated 1080×1920 Xvfb. Existing compact/original-editor registrations retain their default session profile. Supplemental receipts disclose earlier physical-fixture/profile failures; final compact 62 passes in a fresh dedicated runtime. Their initial root cause is not claimed proven.
- Raw full-screen `selector-popup.png` and `selector-custom.png` were inspected. Openbox manages the maximized main window; the selector is an unframed override-redirect 306×328 popup, anchored/flipped above the actual bottom toolbar by production code. Preset contains all 177 shipped MyPaint resources; Custom displays immutable drafts derived from real resources. No fake screenshots or replacement UI are used.

Tests use the accessible production button action and device-associated synthesized GTK keyboard events after establishing native focus; these are **not physical X-server input**. The outside-policy test invokes the native button-press vfunc because `gtk_widget_event()` reports TRUE when its widget is destroyed even if the vfunc returns FALSE. The actual selector host, anchor ownership, GTK grab, resource/model values and destroyed/reopened identities are checked independently.

The actual canvas test locates the independent compact toolbar by its parent and owning shell—not an arbitrary same-named selector in a hidden attached dock. Detached factory fixtures are mapped before clicking. The stroke fixture resets Undo through freeze/free/thaw so the visible native Undo editor is rebuilt; real stroke pixels, Undo and canceled-stroke assertions remain intact.

## Scope and reproduction

Production changes are confined to `app/widgets/gimpmypaintbrushoptions-gui.cpp`; existing selector C/C++ contract tests are extended. The carrier, standard `GimpContainerPopup`, editor, resource backend, immutable history model, FilterLayer routes and other toolbar popup families are unchanged. This selector contains no nested stock-brush selector; none is claimed as a tested production entry. Source-derived legacy semantics are documented in `legacy-source-contract.md`; the old application was not run. Whole-port completion, all-popup completion and old-runtime visual/layout equivalence are **not** claimed. Parent WBS 24.015 remains open.

Build the normal `mypaint-selector-contracts` Meson target and run it with the repository's `tools/run-painter-xvfb.py` wrapper and `GIMP_TESTING_SESSIONRC_NAME=sessionrc-native-oncanvas`. For a portrait capture, select `/mypaint-selector/cpp/19-actual-canvas-real-resources`, run Openbox within that Xvfb session, and set `GIMP_SELECTOR_POPUP_CAPTURE` and `GIMP_SELECTOR_POPUP_CUSTOM_CAPTURE` to desired PNG paths. Capture mode maximizes only the main window. The run uses isolated temporary profiles, real application initialization and the actual production selector; no diagnostic preload is used for acceptance. Source and binary hashes, TAP receipts, negative mutation patch, window properties and sanitizer qualifications accompany this report.
