# Immutable defined-domain Normalize byte kernel

Private C++14/no-RTTI header only, no native route or raster integration. FilterNormalizeStats collects actual ROI RGB/alpha bytes, with alpha!=0 contributing to shared visible extrema. Hidden extrema are tracked independently. finish() returns a by-value kernel independent of later collector edits; no mutable state accessors exist. Its table and status are private, and apply is const. RGB callers can supply alpha255; Gray admission and indexed image ownership are not implemented.

Status distinguishes ready, empty, no_visible_samples and hidden_outside_range. Empty is NOT automatically a native error: a future caller must honor the framework's empty-selection/no-op contract without executing the undefined old range conversion. Nonempty unsupported domains may be refused before publication while retaining existing cache/model/history. This header itself accesses no native owner, shadow, history or I/O. It assigns no invented legacy pixels to undefined domains. Applying any nonready kernel raises a useful logic_error; applying a pixel outside the finalized interval raises invalid_argument. Callers must use the same immutable scanned source. There is no guarantee against mutable-source TOCTOU in this scalar component.

The fixed scalar collector and LUT construction allocate no memory or sample counts. Application returns a four-byte value, preserving alpha and hidden colors' defined mapping; exception construction may allocate. No whole-operation allocation-free claim is made. Transport padding and zero-filled area must not be added to the stats.

Normal and selected header ASan/UBSan tests each pass11,316,224 pixel/alpha checks, all ordered min/max byte pairs, alpha0/1/127/255, flat identity, separately classified empty/nonempty undefined domains, and immutable snapshot checks. Independent integer expected outputs are grounded by the two immutable old-C predecessor packages. Three actual header mutants are rejected. First/double C++14 no-RTTI inclusion is compiled by the same test. No C ABI/header-route inventory is changed.

This does not implement a production procedure, ROI pass, cancellation, indexed ownership, Gray/native precision admission, cache semantics, persistence or UI, nor close WBS16.022. Native admission remains a later bounded task with explicit unsupported-domain reporting and standard empty-selection behavior.
