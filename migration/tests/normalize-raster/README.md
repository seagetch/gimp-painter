# Normalize compact actual-ROI raw transport

New private filter-normalize-raster uses existing FilterRaster/TemporaryFilterRaster and immutable Normalize stats/LUT; it does not duplicate CropRaster, region validation or zero-fill. A future single point-shadow overload must pass the actual compact ROI, not padded full shadow. No native route is admitted here.

Dimensions are bounded to signed32 with selected area<=INT32_MAX, matching the old iterator's defined multiplication domain. Exact independent RGBA8 extents are required and direct aliasing is rejected before I/O. Caller must exclude indirect aliases and retain immutable input across both passes; no claim to detect arbitrary storage mutation. Empty exact-sized input returns a distinct empty outcome without I/O (cancellation takes priority), allowing future framework no-op semantics without invoking old undefined normalization.

Pass1 reads actual pixels in at most32KiB chunks and finalizes visible/nonvisible extrema. Nonempty all-transparent and hidden-outside-visible-range inputs raise useful domain errors before output writes/flush. Pass2 rereads immutable source, applies the finalized LUT, writes bounded output and flushes. Cancellation is checked before/after callbacks and periodically inside both pixel loops. Progress covers scan then output and only reaches1 after successful final flush and postflush cancellation check.

**Raw output is not atomic.** Errors/cancellation may leave partially written private output. Only complete can be considered for publication after independent owner/generation checks. This function does not publish pixels or history, and does not itself prove native cache retention. Source stays unchanged for the supplied immutable, independent raster contract. Exceptions from read/write/flush propagate.

Normal and three-translation-unit ASan/UBSan each pass75 cases: five chunk-boundary sizes, independent integer pixel/alpha oracle, actual temporary-file transport, every storage-event ordinal cancellation/exception across both passes/output/final flush, progress nevercomplete on failure, unsupported stats with zero writes, initial cancellation, empty outcome, alias/extent/legacyarea rejection. Same fixture first/double includes public private header under C++14/noRTTI. Three real implementation mutants are rejected: omit flush, contaminate scan extrema, ignore final cancellation. vptr/LSan excluded; dependency GLib not instrumented. sources.tar.gz binds all eight tested inputs. Initial test-host compilation needed anonymous namespace to match private base visibility; no product behavioral failure claimed from that fixture issue.

No full/partial/outside native region proof, owner/component/selection merge, Gray/indexed admission, PDB, XCF or rendered UI is claimed. Those remain explicit16.022 work. This compact transport is intended for sole existing point-shadow integration, not a second authoritative region backend.
