# 09.009 — bounded work-buffer allocation

Original criterion: **必要領域へ制限し上限を扱う**. Fourteen original source duties remain explicit in `work-buffer.json`; none of their inventory statuses is changed. The processor's five-region dispatch, complete Pixel arithmetic header and TempBuf parent-view consumers are not silently renamed allocation-only work. Their precise identities and successor owners remain auditable.

Surface first intersects the dab with target and translated selection extents. Empty intersections allocate no ROI arrays. Before coverage, selection or pixel-vector allocation, checked division admits the clipped area against a **1 GiB per-operation scratch budget**. It reserves128 bytes/pixel plus the retained provider-mask byte count. Actual largest simultaneous wide nonincremental arrays are12 bytes coverage +32 floating +32 baseline +32 output =108 bytes/pixel. Selection scalar decode peaks below that. The conservative128 applies across modes and precisions.

Radius800 remains supported: an ordinary scaled1600-square bitmap rotated at45 degrees fits within2266-square including rounding margins;2266²×129 is662,383,524 bytes, below1 GiB. This is a scratch admission policy, **not** a whole-image/file-size cap, total-stroke-memory cap, GEGL cache setting or guarantee against system OOM. A custom/pipe provider may return larger masks; those are explicitly rejected when retained storage plus clipped scratch exceeds the cap. Providers own allocation before returning; this gate cannot retrospectively bound that external allocation. Resource-transform generation and full consumer replacement retain their own owners.

Oversize operations throw `std::length_error` before target reads/writes, dirty notifications or scratch allocations; reducing the footprint permits a retry in the same Surface session. The existing native session exception boundary returns errors rather than reporting successful painting; this checkpoint does not claim a newly tested GTK error dialog.

Floating GEGL buffers retain the target's logical extent as sparse tile-backed descriptors. Tests use a supplied independent snapshot to avoid claiming constant-time full-image `gegl_buffer_dup`: GEGL0.4.62 copy traverses aligned tile ranges. Million-square logical extents receive only a3×3 dab with exact read/write byte counts. Actual `gegl_stats()` tile allocation deltas remain below16 MiB; reused allocator pools can yield zero delta. This measures pixel tile allocation, not all metadata or a global cache limit. Sparse tests end sessions rather than cancel a huge distant-dab bounding box.

Five normal and five focused ASan/UBSan/float-cast-overflow groups cover exact boundaries/overflow without giant allocation, sparse incremental/nonincremental byte/double sessions, oversized-provider rejection and retry, clipping before admission, translated selection and maximum radius. Dependencies are uninstrumented and LSan is off. Two actual production-helper mutations fail arithmetic assertions without attempting a giant allocation or simulating OOM. Registered native regression results are recorded separately. These are internal model tests, not rendered UI screenshots.
