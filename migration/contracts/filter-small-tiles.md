# Isolated Small Tiles compatibility route

WBS 16.003/isolated-small-tiles-route extends the accepted literal process bridge
and shared owner context. The saved procedure remains `plug-in-small-tiles`,
with its original four typed integer arguments and opaque definition bytes.
Image/drawable integer IDs are retained in the definition but never select a
runtime object. The child binds its own private image and drawable. Invalid
values/types, high precision, unavailable swap/runtime, cancellation and failed
workers preserve the definition and last completed cache with explicit state.

## Native contract

The hidden bundled `plug-in-painter-small-tiles` admits only noninteractive
factor 0..6. The existing public `plug-in-small-tiles` remains 2..6, with its
menu, dialog and normal arithmetic unchanged. Factor 0 samples the operation
rectangle's top-left point and DOES merge; an explicit branch avoids the old
unused floating division by zero. Factor 1 is identity. Native selection bounds
are the permutation domain, so processing a whole image and masking afterward
would be incorrect. A globally nonempty selection outside the drawable performs
no merge and publishes that job's newly prepared lower input, not a stale cache.

The helper validates the exact two registrations, both full public/hidden
signatures, argument ranges/defaults/types and executable identity, then admits
only the hidden entry in its private PDB. The selector is numeric 2 and maps
literally to bundled `tile-small`; saved names, paths, executables and scripts
cannot select a binary. Build/installed/relocated paths retain the existing
worker-side executable-relative lookup rules.

The original task used GPF3 / `--filter-worker-v3` with a 64-byte scalar request.
The Retinex task advances the shared transport to GPF4 / `--filter-worker-v4`;
Small Tiles retains these fields and validates canonical unused Retinex defaults.
GPF3 added the integer factor at byte56 and reserved word60. GPF4 uses
word60 for native storage and rejects old versions, unknown selectors,
noncanonical unused route scalars and invalid geometry. Selected region area must fit signed native progress arithmetic before
input transfer. The bounded RGBA8 carrier triplicates Gray bytes: Small Tiles
only permutes channels, preserving the actual old native Gray values. Both old
alpha-zero hidden colors and final component/own-alpha-lock behavior are merged
through the accepted shared owner context. Worker start captures the ROI; final
selection, components and own alpha lock are captured after completion. No new
Filter execution is caused by context-only edits, and GEGL reads only complete
committed cache. Shared cancellation, dependency, close, reaping and no-partial-
publication boundaries apply unchanged.

## Evidence

`../fixtures/small-tiles-evidence.tar.gz` is a derived exact-byte subset of three
preserved 2026-10-02/03 mixed captures. It is not a new old-runtime capture.
The original reports and provenance bytes remain unchanged; the manifest links
every retained member to its original archive SHA256/member hash. Its 196 genuine
old standalone outputs cover RGB/RGBA/Gray/GrayA, factors 0..6, seven geometries,
non-divisible dimensions and tile boundaries. Twenty-five actual old live scenes
provide 48 native merges plus two outside-selection no-merge generations.
Twenty-four historical public calls before/after the hidden adapter have equal
signatures and output. Hidden historical matrices are corroborating evidence,
not a substitute for current helper/native execution.

Current command outcomes, exact source/executable hashes, standalone comparison
counts, native tests, fresh public/hidden PDB calls, sanitizer scope and installed
runtime proof are recorded separately in `../tests/filter-small-tiles/`.
Analytic permutations and shared-context checks are not counted as old fixtures.

## Limits

This is a bounded U8 nonlinear RGB/Gray route. The existing conservative 1 GiB
memory admission, configurable spill with an 8 GiB default, disabled-swap failure, logical rather
than physical space reservation, global latency and
Windows/macOS process gates remain explicit. A normal native suite pass is not
a whole-application release pass. Retinex, XCF multipart, remaining procedures
and unrelated migration gates are outside this task.

Generation-scoped owner/editor progress is now covered by `filter-progress.md`.
